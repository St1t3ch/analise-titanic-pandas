# Análisea de Dados - Titanic

**Usando Pandas.**

Fiz essa análise para praticar limpeza de dados, feature engineering e visualizações.

## O que fiz:
- Carreguei e explorei o dataset do Titanic
- Fiz limpeza de dados (tratamento de valores faltantes)
- Criei novas colunas (título da pessoa, tamanho da família, viajou sozinho)
- Criei visualizações para entender os padrões de sobrevivência

## Principais descobertas:
- A taxa geral de sobrevivência foi de cerca de **38%**
- Mulheres tiveram muito mais chance de sobreviver que homens
- Passageiros da 1ª classe tiveram prioridade no resgate
- Crianças e pessoas com títulos mais "nobres" tiveram maior taxa de sobrevivência
- Quem viajava sozinho teve menos chance de sobreviver

## Tecnologias usadas:
- Python
- Pandas
- Matplotlib + Seaborn
- Jupyter Notebook
